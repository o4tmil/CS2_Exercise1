# CS2_Exercise1

## Description
- Determines if a number, inputted by the user, is **odd** or **even**.

## How to Run
1. Open the file in an IDE.
2. Run the program.
3. Enter a number.
4. Look at the answer displayed on the screen (Even or Odd).

## Input Needed
- number

## Sample Output
Enter a number: 4

4 is even.
